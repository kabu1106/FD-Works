# FD-Works 勤怠管理システム

消防署の勤怠管理システムをNext.jsで実装したWebアプリケーションです。

## 機能

### 勤務表機能（実装済み）

- 24時間勤務の仮眠時間グループ管理
  - [1番起]24:00〜30:45
  - [2番起]22:00〜24:00,26:00〜30:45
  - [3番起]22:00〜26:00,28:00〜30:45
  - [4番起]21:15〜28:00
- 週休の管理
- 職員のドラッグ&ドロップによる配置
- 所属による職員フィルタリング
- 職員の重複配置の防止
- 特別休暇の登録（年次休暇、夏季休暇、慶弔休暇など）
- スマートフォン対応（タップで職員追加）
- データのローカルストレージへの保存

## 技術スタック

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- date-fns

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build

# 本番サーバーの起動
npm start
```

## 使用方法

1. ダッシュボードから「勤務表」を選択
2. 日付を選択して勤務表を作成
3. 職員をドラッグ&ドロップで仮眠時間グループや週休に配置
4. 特別休暇を登録する場合は、職員・休暇種別・時間を入力
5. データは自動的にローカルストレージに保存されます
